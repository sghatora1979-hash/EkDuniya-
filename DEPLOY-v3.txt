## Deploy
1. Download zip, extract.
2. Upload ALL files to GitHub repo **EkDuniya** (replace existing).
   Click-only: Add file → Upload files → Choose files → Commit changes.
3. Vercel auto-deploys (~2 min).

## One-time: run migrations (Supabase → SQL Editor → New query → Run)
Run EACH of these once (skip any already run):
- supabase/migrations/002_stories.sql  (Stories table)
- supabase/migrations/003_lives.sql    (Live streams table)
- supabase/migrations/004_social_links.sql  (profile social links column)

## If /register still says "Failed to fetch"
Open live /register → tap **Test connection** → follow what it says.
Most likely: Vercel → Settings → Environment Variables → check
NEXT_PUBLIC_SUPABASE_URL + NEXT_PUBLIC_SUPABASE_ANON_KEY → Redeploy.
